# Окно — помощник по свободному времени в Астане

Build with AI Hackathon (AITU × GDG Astana), трек **AI for Smart City**, кейс НИЦ Smart City «ИИ-помощник по прогулкам».

> «Я в ЭКСПО, к 19:00 надо быть в Хан Шатыре» → 1–3 места по пути, которые ты **точно успеешь**:
> реальное время пешком по улицам, часы работы **на момент прихода**, погода и ветер, пробки для такси.
> Только реальные места из OpenStreetMap — ничего не выдумано; где данных нет, так и пишем.

## Как это работает (RAG)
1. **Понимание запроса** — Gemini превращает фразу в структуру: откуда, куда, к скольки, пожелания, язык.
2. **Поиск (Retrieval)** — алгоритм отбирает места из базы OSM (1289 мест) и перебирает сотни вариантов маршрута:
   - время пешком (OSRM по улицам), такси — с поправкой на час пик;
   - часы работы проверяются на весь визит; нет данных → «оценка»;
   - мороз и ветер (Open-Meteo): на улице не больше 12–35 мин подряд, уличные места отпадают;
   - темнота: парки и площадки не предлагаются; с ребёнком — свои места.
3. **Генерация** — Gemini пишет «почему» и «что делать» **только по фактам** из шага 2. Места выбирает алгоритм, не ИИ.

## Запуск
```bash
python -m venv .venv && .venv/Scripts/pip install -r requirements.txt   # Windows
cp .env.example .env    # вписать ключ OpenRouter
python -m uvicorn app.main:app --port 8000
# открыть http://localhost:8000
```
Ссылка сразу на сценарий: `http://localhost:8000/?q=Я у Байтерека, вылет в 18:30&t=15:00&w=cold`

## Структура
- `scripts/collect_osm.py` — автоматический сбор мест из OpenStreetMap → `data/poi.json` (GitHub Actions обновляет раз в неделю).
- `scripts/build_landmarks.py` — справочник ориентиров (ЭКСПО, Байтерек, аэропорт, вокзалы…).
- `app/planner.py` — планировщик маршрута · `app/hours.py` — часы работы · `app/geo.py` — маршруты, погода, пробки · `app/llm.py` — Gemini.
- `static/index.html` — интерфейс (карта OpenFreeMap + MapLibre).
- `scripts/stress.py` — стресс-тест: случайные запросы, проверка «не опоздал» и «всё открыто».
- `docs/research.md` — исследование: конкуренты, данные, выбор идеи.

## Приватность и честность
- Точка пользователя округляется до ~150 м и нигде не сохраняется; запросы не логируются.
- Каждая рекомендация помечена: источник места (OSM, ссылка), надёжность часов (проверено / оценка), текст от ИИ.
- Чего мы не знаем: рейтинги, очереди, временные закрытия, живые пробки, розетки — и так и говорим.
