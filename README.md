# Окно — помощник по свободному времени в Астане

Build with AI Hackathon (AITU × GDG Astana), трек **AI for Smart City**, кейс НИЦ Smart City «ИИ-помощник по прогулкам».

У тебя есть свободное окно — между парами, встречами, до вылета. «Окно» подбирает 1–3 места по пути из точки А в точку Б так,
чтобы ты точно успел: с реальным временем пешком, проверкой часов работы на момент прихода и учётом погоды и ветра.
Только реальные места из базы — ничего не выдумано; где данных нет, так и пишем.

## Что уже есть
- `scripts/collect_osm.py` — автоматический сбор мест Астаны из OpenStreetMap (Overpass API) → `data/poi.json`.
- `.github/workflows/update-poi.yml` — GitHub сам пересобирает базу раз в неделю.
- `mockup/okno.html` — кликабельный макет интерфейса (открыть в браузере).
- `docs/research.md` — исследование: конкуренты, данные, выбор идеи.
