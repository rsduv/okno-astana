# Датасет мест Астаны («Окно»)

Собран автоматически 19.10.2026. Мест: **1304**. Файлы: `data/dataset/astana_poi.csv` (открывается в Excel) и `data/dataset/astana_poi.jsonl`.

## Как собирается (без ручной работы)

1. `scripts/collect_osm.py` — запрос в OpenStreetMap (Overpass API) по прямоугольнику Астаны: кафе, рестораны, музеи, парки, ТРЦ, памятники, площадки и т.д. → `data/poi.json`.
2. `scripts/collect_wiki.py` — Wikidata/Википедия: известные места, описание, фото, названия на EN/KZ → `data/wiki.json`.
3. `scripts/collect_city.py` — границы 6 районов Астаны и станции LRT из OSM → `data/districts.json`, `data/lrt.json`.
4. `scripts/collect_events.py` — афиша Astana Opera → `data/events.json` (ежедневно).
5. `scripts/build_dataset.py` — сводит всё в одну таблицу с полями из ТЗ и источником каждого поля.

GitHub Actions пересобирает базу каждый понедельник (`update-poi.yml`) и афишу каждый день (`update-events.yml`).
Данные 2GIS продукт использует для уточнения часов/рейтинга на лету, но в открытый датасет их не кладём — условия 2GIS не разрешают публикацию.

## Поля

| Поле из ТЗ | Колонки | Заполнено | Откуда |
|---|---|---|---|
| Название | name, name_en, name_kk | 100% / 12% / 7% | OSM, Wikidata |
| Координаты | lat, lon | 100% | OSM / Wikidata |
| Короткое описание | description, description_source | 100% | osm:tags: 1279, wikipedia: 24, osm:description: 1 |
| Категория / теги | category, tags | 100% | теги OSM → 28 категорий |
| Время работы | opening_hours, hours_source | 100% | typical-for-category (не проверено): 483, outdoor (открытое место; ночью и в мороз продукт это учитывает): 431, osm: 361, osm:mall: 29 |
| Контакты | phone, website, instagram, address | тел. 15%, сайт 15%, адрес 12% | OSM |
| Что делать / сколько времени | what_to_do, visit_min | 100% | шаблон по категории (продукт уточняет под запрос) |
| Где это | near_landmark, near_landmark_m | 73% | ближайший из 32 ориентиров, до 1,5 км |
| Район города | district | 100% | границы районов из OSM (`scripts/collect_city.py`) |
| Транспорт | lrt_station, lrt_station_m | 26% | ближайшая станция LRT до 1,2 км (OSM, линия открыта 16.05.2026) |
| Рейтинг / популярность | popularity (0–1), popularity_source | 100% | статья в Википедии на N языках + подробность в OSM |

**Честно о дырах:** у части мест часы — типичные для категории, это помечено в `hours_source` («не проверено»), и продукт в этом случае пишет «обычно открыто», а не «открыто». Рейтингов в открытых данных нет: `popularity` — это известность места, а не оценка. Описание `osm:tags` собрано из фактов OSM (кухня, веранда, Wi-Fi, адрес) — ничего не придумано ИИ.
