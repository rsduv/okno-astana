# Загрузка демо-видео на YouTube

Файл: `video/okno_demo.mp4` (3:19, 1920×1080, без звука, с подписями на экране). Пересобрать: `python scripts/record_demo.py`.
Доступ: **«Доступ по ссылке»** (как требует кейс). Ссылку вставить в форму сдачи и в README.

**Название:**
Окно — ИИ-помощник по свободному времени в Астане (RAG) · Build with AI Hackathon, AI for Smart City

**Описание:**
Окно подбирает 1–3 реальных места по пути так, чтобы ты точно успел: реальное время пешком, часы работы на момент прихода,
погода по часам маршрута, пробки 2GIS. Пишешь одной фразой — на русском, казахском или английском, можно голосом.

RAG: Gemini понимает запрос → алгоритм ищет по базе из 1465 мест (OpenStreetMap + 2GIS + Wikidata) и перебирает сотни маршрутов →
Gemini пишет «почему» и «что делать» только по фактам. Места выбирает алгоритм, поэтому ИИ не может придумать несуществующее кафе.

Проверено: 44/44 автопроверок в 13 сценариях; 100 случайных запросов — 0 опозданий и 0 закрытых мест;
на 30 одинаковых запросах: Claude без данных — 5 ответов с ошибками, тот же Gemini без наших данных — 4, Окно (Gemini + RAG) — 0.
Для города — обезличенная статистика спроса: что ищут люди и чего им не хватило.
