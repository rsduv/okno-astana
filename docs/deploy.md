# Выложить «Окно» в интернет (Render, бесплатно) — 5 минут

1. Зайти на https://render.com → **Get Started** → войти через **GitHub** (аккаунт rsduv).
2. **New → Blueprint** → выбрать репозиторий `okno-astana` → Render сам прочитает `render.yaml`.
3. Ввести ключи (их значения — в файле `.env` на компьютере):
   - `GEMINI_API_KEY`
   - `OPENROUTER_API_KEY`
   - `DGIS_KEY`
4. **Environment → Secret Files** → добавить два файла из папки `data/` (в GitHub их нет):
   - `dgis_pois.json` — популярные места 2GIS;
   - `dgis_cache.json` — уже проверенные часы и рейтинги (чтобы не сжечь дневной лимит 2GIS).
5. **Deploy** → через 3–5 минут будет адрес вида `https://okno-astana.onrender.com`.

Проверить: открыть адрес с телефона — должно спросить геолокацию (на https она работает), нажать «примеры», построить маршрут.

Особенности бесплатного плана: после 15 минут без посетителей сервис «засыпает», первый запрос после сна — ~30–50 секунд.
Перед показом жюри — открыть сайт заранее, чтобы «разбудить».
